Reaper pending macet + retry dari UI + timeout LLM per-call / Stuck-pending reaper plus UI retry plus per-call LLM timeout

Summary
ID: Baris cover pending yang kehabisan attempts kini dipanen jadi failed dengan pesan jujur, bisa diulang dari UI, dan waterfall LLM dibatasi timeout 90 dtk per call. / EN: Pending cover rows with exhausted attempts are now reaped to failed with an honest message, retryable from UI, and the LLM waterfall is capped by a 90s per-call timeout.

Prior Condition & Problem

ID: Tick worker (maxDuration 300 dtk) dibunuh saat provider LLM terdepan menggantung 138-300 dtk; baris cover pending attempts 3/3 tak pernah diklaim lagi dan UI tak punya tombol Ulangi (khusus failed); automation menunggu 60 menit sia-sia. / EN: The worker tick (maxDuration 300s) was killed while the leading LLM provider hung for 138-300s; pending cover rows at 3/3 attempts were never claimed again and the UI had no retry button (failed-only); automation waited 60 minutes in vain.

Reason & Motivation

ID: Visualisasi draf automation berhenti total tanpa jalur pemulihan; perlu recovery prod + perbaikan sistemik. / EN: Automation draft visualization halted completely with no recovery path; needed prod recovery plus systemic fix.

Applied Solution

ID: Konstanta bersama IMAGE_MAX_ATTEMPTS/isExhaustedPending; reapStuckImages() di awal processImageTick; retryFailedImage menerima pending-exhausted; badge Macet + tombol Ulangi di carousel; ensureCover requeue pending macet; fetchWithTimeout 90 dtk di 3 provider LLM; pin stage image_prompt ke cloudflare gemma-sea-lion. / EN: Shared IMAGE_MAX_ATTEMPTS/isExhaustedPending constants; reapStuckImages() at the start of processImageTick; retryFailedImage accepts exhausted-pending; Stuck badge plus retry button in carousel; ensureCover requeues stuck-pending rows; 90s fetchWithTimeout in 3 LLM providers; image_prompt stage pinned to cloudflare gemma-sea-lion.
